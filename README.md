# Warattil

Warattil is a private application used only by the owner of the Warattil YouTube channel (Quran recitations). It turns the owner's own recitation recordings into videos, uploads them to the owner's own channel, and prepares weekly reports for the owner.

## Privacy Policy

Data accessed: the owner's own YouTube channel (uploads, playlists, thumbnails, branding), the channel's YouTube Analytics reports, and recitation files in the owner's own Google Drive folders.

Purpose: publishing the owner's recitations and managing the owner's channel only. No data is shared with third parties, sold, or used for advertising.

Authorization tokens are stored only in the owner's private settings. Access can be revoked at any time at myaccount.google.com/permissions.

The app complies with the Google API Services User Data Policy and the YouTube Terms of Service.

## Terms of Use

For the channel owner's personal use only.
